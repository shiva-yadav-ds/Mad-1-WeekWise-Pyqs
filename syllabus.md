Week	Content
1	Basic terminologies of Web: What is an app, Components of an app, Client-Server and Peer-to-Peer architecture, Software architectures, How the web works, Simple web server, Protocols, Website performance
2	Webpages written in HTML and CSS: Information representation and encoding, Markup languages, Introduction to HTML, Internal and external CSS, Serving HTML files on LAN, Browser developer tools
3	Presentation layer - View: String formatting in Python, f-strings, Introduction to Jinja2 templating, Generating dynamic HTML documents using Jinja2
4	Models - Introduction to databases: SQLite basics, Exploring SQLite databases, Introduction to ORMs, SQLAlchemy setup, Models, Engine, Connection, Session, Running queries, Transactions
5	Controllers - Business logic: Introduction to Flask framework, Building a simple Flask application, Routing, Handling HTTP requests and responses, Connecting views and models
6	APIs and REST APIs: Application Programming Interfaces, REST architectural principles, Designing RESTful endpoints, JSON data exchange, Building APIs using Flask-RESTful
7	Backend Systems: Server-side architecture, Managing application state, Session management, Background processing, Integrating external services and databases
8	Application Frontend: Structuring multi-page web applications, Forms and user input validation, Client-side interactions, Improving UI/UX workflows
9	Application Security: Web security fundamentals, Authentication and authorization, Protecting user data, Common web vulnerabilities and mitigation
10	Testing of Web Applications: Importance of software testing, Unit testing, Integration testing, Debugging and testing Flask applications
11	HTML Evolution and Beyond HTML: Evolution of web standards, HTML5 features, Semantic web, Accessibility, Modern web capabilities
12	Application Deployment: Hosting web applications, Server environments, Deployment workflows, Production considerations and scaling
