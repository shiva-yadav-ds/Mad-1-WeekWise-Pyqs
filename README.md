# Application Development-1 question portal

Run from this folder:

```bash
python3 -m http.server 8003 --bind 127.0.0.1
```

Open http://localhost:8003. No package installation is needed to use the site.

The 12 week PDFs are in `output/pdf/`. The syllabus-based source/question mapping is in `Application_Development_1_weekwise_question_mapping.md`.

The final website, PDFs, syllabus, mapping and verification notes are retained.

The current selection contains 725 representative questions; 319 repeated variants are excluded. Their retained representatives and reasons are listed in the mapping.
